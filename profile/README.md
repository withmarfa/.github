**WithMarfa** makes Marfa, a home for your personal data that you run yourself, and the apps and connectors built on it. It is an early project, and everything is open source.

- [marfa](https://github.com/withmarfa/marfa): the server, the command-line tool and the written contract
- [marfa-connectors](https://github.com/withmarfa/marfa-connectors): bring data in from other services
- [marfa-swift](https://github.com/withmarfa/marfa-swift): the Swift package for Apple apps
