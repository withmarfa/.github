**WithMarfa** makes Marfa, a home for your personal data that you run yourself, and the apps and plugins built on it. It is an early project, and everything is open source.

- [marfa](https://github.com/withmarfa/marfa): the server, the command-line tool and the written contract
- [plugins](https://github.com/withmarfa/plugins): connectors that bring data in from other services, and common type families
- [marfa-swift](https://github.com/withmarfa/marfa-swift): the Swift package for Apple apps
